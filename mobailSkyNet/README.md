# SkyNet Mobile

Автономное Android-приложение службы интернет-поддержки на `Python`, ориентированное на `KivyMD` и локальную работу без backend.

## Что реализовано

- главная страница с публичной формой обращения
- локальная регистрация, вход, выход, восстановление и смена пароля
- профиль пользователя и редактирование личных данных
- роли: гость, клиент, оператор, администратор
- список заявок, карточка заявки, комментарии, статусы, исполнители и вложения
- база знаний со статьями и импортом из текста
- административные разделы: панель, отчёты, пользователи и журнал действий
- локальная SQLite-база с начальными данными

## Локальные данные

При первом запуске создаётся база `storage/skynet_mobile.db` с демо-данными.

Тестовые учётные записи:

- `admin` / `admin123`
- `operator` / `operator123`
- `ivan.petrov` / `client123`

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
KIVY_HOME="$(pwd)/.kivy" .venv/bin/python main.py
```

Если `KivyMD` временно не установлен, приложение использует совместимый fallback на обычных `Kivy`-виджетах.

## .env и восстановление пароля

В проект перенесён шаблон `.env` по образцу веб-версии.

- `.env.example` содержит безопасный шаблон переменных
- `.env` уже создан для локального запуска
- поддерживаются `SECRET_KEY`, `PASSWORD_RESET_EXPIRE_MINUTES` и блок `MAIL_*`

Сценарий восстановления теперь повторяет веб-логику:

- пользователь вводит `email`
- приложение создаёт 6-значный код
- если SMTP настроен через `.env`, код отправляется на почту
- если SMTP не настроен, код показывается локально в приложении
- код действует ограниченное время и затем становится недействительным

## Android

Для сборки под Android подготовлен `buildozer.spec`.

Базовая схема:

```bash
buildozer android debug
```

## Примечание

Приложение повторяет структуру и ключевые сценарии сайта, но работает полностью локально через SQLite и не требует подключения к серверу.
