## 1. Общая архитектура

- Два клиента одной предметной области «служба поддержки / заявки / база знаний»: веб-браузер и мобильное приложение
- Серверная часть — монолитное Flask-приложение `skynet_web` (единый процесс, blueprints `main`, `auth`, `api`)
- Веб хранит данные в СУБД на сервере: по умолчанию SQLite (`instance/skynet.db`), опционально PostgreSQL через переменную `DATABASE_URL`
- Мобильное приложение `mobailSkyNet` — автономный офлайн-клиент на Kivy/KivyMD с локальной SQLite (`storage/skynet_mobile.db`), без обязательной синхронизации с сервером в коде
- Общая логика домена: пользователи, роли, заявки, статусы, категории, комментарии, вложения, база знаний, журналы, отчёты
- Разделение хранения: веб — централизованная БД + файловые uploads; мобильное — локальная БД + локальные exports/аватары
- Внешние зависимости веба: SMTP (уведомления, сброс пароля), опционально OpenRouter API (рекомендации статей БЗ)
- Точка входа веба: `run.py` → `create_app()` в `app/__init__.py`
- Точка входа мобильного: `main.py` → `SkyNetApp` в `skynet_app/app.py`
- Docker в репозитории не используется
- Диаграмма архитектуры: `kp_romanov/diagrams/skynet_architecture.mmd`

### 4.7. Бизнес-правила API (ключевые)

- Пагинация заявок: 20 на страницу (`PER_PAGE`), макс. 100
- Переходы статусов: `draft→new`; `new→in_progress|resolved|closed`; `in_progress→resolved|closed`; `resolved→closed`; `closed` — терминальный
- Клиент видит только свои заявки (`ticket_scope`)
- Редактирование текста заявки автором — в течение 1 часа после создания
- Удаление: админ всегда; автор — только статус «Черновик» (`draft`)
- Описание заявки: до 5000 символов; вложение: до 10 МБ

## 5. Аутентификация и безопасность

- **Механизм:** Flask-Login, серверная сессия в cookie (`session`, опционально `remember_token`)
- **Не используется:** JWT, OAuth, API-ключи для пользователей
- **Хеширование паролей (веб):** `bcrypt` (`bcrypt.hashpw`, rounds=12) в `routes/auth.py`; не Werkzeug `generate_password_hash` (Werkzeug в зависимостях, но auth — bcrypt)
- **Политика пароля:** мин. 8 символов, цифра, спецсимвол (`app/auth_utils.py` — `check_password_policy`)
- **Brute-force:** таблица `Login_attempts`; блокировка после 5 неудачных попыток за 15 мин (`MAX_LOGIN_ATTEMPTS`, `LOCKOUT_MINUTES`)
- **Сброс пароля:** таблица `Password_reset_tokens`; токен `secrets.token_urlsafe(32)`, хеш токена bcrypt; срок `PASSWORD_RESET_EXPIRE_MINUTES` (60); одноразовый (`used`)
- **CSRF:** Flask-WTF для HTML; API без CSRF
- **Неавторизованный API:** JSON `401` вместо редиректа (`unauthorized_handler` в `__init__.py`)
- **Мобильное:** локальная проверка `password_hash` (SHA-256); сброс через `password_resets` (код 6 цифр или SMTP)

| 3 | **Statuses** | `status_ID` | — |
| 4 | **Categories** | `category_ID` | — |
| 5 | **Tickets** | `ticket_ID` | `author_ID`→Users, `assignee_ID`→Users, `category_ID`→Categories, `status_ID`→Statuses |

## 9. Ключевой функционал

### 9.1. Заявки (tickets)

- Создание авторизованным клиентом или через API/HTML
- Гостевая форма: `POST /api/guest-ticket` — только для существующего email
- Поля: title, description (≤5000), category, priority (low/medium/high), assignee, organization
- Статусы с контролем переходов; запись в `Logs` при смене статуса
- Мягкое удаление на сервере; жёсткое на мобильном
- История завершённых: `/history`, `GET /api/tickets/history`

### 9.2. Комментарии

- Таблица `Comments` / `comments`; привязка к ticket и user
- API: `GET .../comments`, `POST /api/comments`
- Мобильное: `add_comment`, отображение в `TicketDetailScreen`

### 9.3. Вложения

- Сервер: `Attachments`, хранение в `uploads/attachments/`, лимит 10 МБ
- API upload/download; гостевая заявка поддерживает файл
- Мобильное: метаданные в `attachments` (path может быть пустым — демо)

### 9.4. База знаний

- CRUD статей; категории; публичный просмотр без входа (веб)
- Поиск и ранжирование; `POST /api/knowledge/recommend` — OpenRouter + fallback по ключевым словам
- Импорт .txt: `POST /api/knowledge/import` (заголовки `#` / `##`)
- Seed: 50 статей (`seed_knowledge_50.py`)
- Санитизация HTML в `main.format_article_content`

### 9.5. Отчёты и экспорт

- CSV заявок: `GET /api/tickets/export/csv` (UTF-8-BOM)
- XLSX операторов: `GET /api/reports/operators.xlsx` (openpyxl)

| API для мобильного | `/api/*` с cookie-сессией | **Не вызывается** — только LocalRepository |
